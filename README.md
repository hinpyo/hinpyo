## About Me

안녕하세요. 제품을 기획하고 직접 만들어 출시하는 인디 해커 **홍인표**입니다.

문제를 단순히 기능으로 해결하기보다,
그 안에 숨어 있는 구조와 사용자의 필요를 먼저 이해하려고 합니다.

제품의 문제 정의부터 정보 구조, 사용자 경험, 개발까지 연결하며
작지만 분명한 가치를 제공하는 독립 소프트웨어를 만들고 있습니다.
